# Desarrollo web y frameworks

Repositorio de ejercicios y proyectos realizados durante un curso de desarrollo web y frameworks. Los retos están organizados por niveles y cubren frontend, backend, APIs, persistencia, seguridad y aplicaciones full stack.

## Nivel 3 - Frontend

- [Reto 1 - Lista de elementos](NIVEL%203%20-%20FRONTEND/Reto%201/lista-elementos/): aplicación Angular para añadir y mostrar elementos en una lista.
- [Reto 2 - Visualizador de props](NIVEL%203%20-%20FRONTEND/Reto%202/visualizador-props/): aplicación React para practicar el uso de props, estado, eventos y efectos.
- [Reto 3 - Lista de tareas](NIVEL%203%20-%20FRONTEND/Reto%203/): interfaz con HTML, CSS, JavaScript y jQuery para añadir tareas, asignar prioridades y modificar la lista.
- [Reto 4 - Peticiones AJAX](NIVEL%203%20-%20FRONTEND/Reto%204/): cliente que consulta la API Dog CEO y muestra imágenes aleatorias o filtradas por raza.

## Nivel 4 - Backend

- [Reto 1 - API REST con Express](NIVEL%204%20-%20BACKEND/Reto%201/): API CRUD de usuarios desarrollada con Node.js y Express, con documentación OpenAPI y Swagger UI.
- [Reto 2 - API REST con Spring Boot](NIVEL%204%20-%20BACKEND/Reto%202/reto2/demo/): API CRUD de productos con Spring Boot, Spring Data JPA y una base de datos H2.
- [Reto 3 - Persistencia con Hibernate](NIVEL%204%20-%20BACKEND/Reto%203/hibernate/): aplicación Java que practica las operaciones CRUD de usuarios con Hibernate ORM y H2.
- [Reto 4 - Aplicación Symfony](NIVEL%204%20-%20BACKEND/Reto%204/reto4/): aplicación web MVC con Symfony y Twig, incluyendo controladores, rutas y vistas.
- [Reto 5 - Aplicación Laminas](NIVEL%204%20-%20BACKEND/Reto%205/reto5/): aplicación MVC con Laminas para gestionar comentarios, con persistencia JSON, validación y pruebas.

## Nivel 5 - Backend avanzado

- [Reto 1 - Directiva Angular](NIVEL%205%20-%20BACKEND%20AVANZADO/Reto%201/reto1-directiva/): directiva personalizada para filtrar y ordenar dinámicamente los datos de una tabla.
- [Reto 2 - Aplicación Next.js](NIVEL%205%20-%20BACKEND%20AVANZADO/Reto%202/reto2/): proyecto base desarrollado con Next.js para trabajar con aplicaciones React del lado del servidor.
- [Reto 3 - Microservicio de clientes](NIVEL%205%20-%20BACKEND%20AVANZADO/Reto%203/microservicio/microservicio/): microservicio Spring Boot con API CRUD de clientes, JPA, Hibernate y H2.
- [Reto 4 - Hibernate optimizado](NIVEL%205%20-%20BACKEND%20AVANZADO/Reto%204/hibernate/): proyecto Hibernate con una versión original y otra optimizada para comparar mejoras en la aplicación.

## Nivel 6 - Frontend avanzado

- [Reto 1 - Seguridad en Symfony](NIVEL%206%20-%20FRONTEND%20AVANZADO/Reto%201/my_project/): aplicación Symfony con autenticación, autorización, roles, CSRF, voters y sanitización de contenido.
- [Reto 2 - Módulo de comentarios con Laminas](NIVEL%206%20-%20FRONTEND%20AVANZADO/Reto%202/reto2/): módulo MVC para consultar, crear, editar y eliminar comentarios según los permisos del usuario.
- [Reto 3 - Gestión de usuarios full stack](NIVEL%206%20-%20FRONTEND%20AVANZADO/Reto%203/): frontend React con Vite y backend Node.js con Express comunicados mediante una API REST.
- [Reto 4 - Plataforma de eventos](NIVEL%206%20-%20FRONTEND%20AVANZADO/Reto%204/reto4/): aplicación full stack para gestionar eventos, con Angular, Spring Boot, MongoDB, autenticación JWT y pruebas de carga.
- [Reto 5 - Aplicación de notas Noto](NIVEL%206%20-%20FRONTEND%20AVANZADO/Reto%205/reto5/): aplicación Angular de notas con calendario y tablero, sincronización con Firebase, funcionamiento offline y formato PWA.

## Tecnologías principales

Angular, React, Next.js, JavaScript, TypeScript, Node.js, Express, PHP, Symfony, Laminas, Java, Spring Boot, Hibernate, MongoDB, Firebase y bases de datos H2.
