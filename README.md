# Desarrollo web y frameworks

Repositorio de ejercicios y proyectos realizados durante un curso de desarrollo web y frameworks. Los retos están organizados por niveles y cubren frontend, backend, APIs, persistencia, seguridad y aplicaciones full stack.

## Nivel 3 - Frontend

- [Reto 1 - Lista de elementos](Nivel%203%20-%20Frontend/Reto%201%20-%20Crear%20una%20aplicaci%C3%B3n%20b%C3%A1sica%20con%20Angular/README.md): aplicación Angular para añadir y mostrar elementos en una lista.
- [Reto 2 - Visualizador de props](Nivel%203%20-%20Frontend/Reto%202%20-%20Crear%20un%20componente%20React/README.md): aplicación React para practicar el uso de props, estado, eventos y efectos.
- [Reto 3 - Lista de tareas](Nivel%203%20-%20Frontend/Reto%203%20-%20Manipulaci%C3%B3n%20del%20DOM%20con%20jQuery/README.md): interfaz con HTML, CSS, JavaScript y jQuery para añadir tareas, asignar prioridades y modificar la lista.
- [Reto 4 - Peticiones AJAX](Nivel%203%20-%20Frontend/Reto%204%20-%20Crear%20una%20petici%C3%B3n%20AJAX/README.md): cliente que consulta la API Dog CEO y muestra imágenes aleatorias o filtradas por raza.

## Nivel 4 - Backend

- [Reto 1 - API REST con Express](Nivel%204%20-%20Backend/Reto%201%20-%20Crear%20una%20API%20RESTful%20con%20Node.js/README.md): API CRUD de usuarios desarrollada con Node.js y Express, con documentación OpenAPI y Swagger UI.
- [Reto 2 - API REST con Spring Boot](Nivel%204%20-%20Backend/Reto%202%20-%20Implementar%20la%20inyecci%C3%B3n%20de%20dependencias%20en%20Spring/README.md): API CRUD de productos con Spring Boot, Spring Data JPA y una base de datos H2.
- [Reto 3 - Persistencia con Hibernate](Nivel%204%20-%20Backend/Reto%203%20-%20Mapeo%20objeto-relacional%20con%20Hibernate/hibernate/README.md): aplicación Java que practica las operaciones CRUD de usuarios con Hibernate ORM y H2.
- [Reto 4 - Aplicación Symfony](Nivel%204%20-%20Backend/Reto%204%20-%20Crear%20un%20proyecto%20web%20utilizando%20Symfony/README.md): aplicación web MVC con Symfony y Twig, incluyendo controladores, rutas y vistas.
- [Reto 5 - Aplicación Laminas](Nivel%204%20-%20Backend/Reto%205%20-%20Implementar%20un%20formulario%20de%20contacto%20con%20Zend/README.md): aplicación MVC con Laminas para gestionar comentarios, con persistencia JSON, validación y pruebas.

## Nivel 5 - Backend avanzado

- [Reto 1 - Directiva Angular](Nivel%205%20-%20Backend%20Avanzado/Reto%201%20-%20Directivas%20personalizadas%20en%20Angular/README.md): directiva personalizada para filtrar y ordenar dinámicamente los datos de una tabla.
- [Reto 2 - Aplicación Next.js](Nivel%205%20-%20Backend%20Avanzado/Reto%202%20-%20Implementaci%C3%B3n%20de%20React%20Hooks/README.md): proyecto base desarrollado con Next.js para trabajar con aplicaciones React del lado del servidor.
- [Reto 3 - Microservicio de clientes](Nivel%205%20-%20Backend%20Avanzado/Reto%203%20-%20Creaci%C3%B3n%20de%20un%20microservicio%20con%20Spring%20Boot/README.md): microservicio Spring Boot con API CRUD de clientes, JPA, Hibernate y H2.
- [Reto 4 - Hibernate optimizado](Nivel%205%20-%20Backend%20Avanzado/Reto%204%20-%20Optimizaci%C3%B3n%20de%20consultas%20en%20Hibernate/README.md): proyecto Hibernate con una versión original y otra optimizada para comparar mejoras en la aplicación.

## Nivel 6 - Frontend avanzado

- [Reto 1 - Seguridad en Symfony](Nivel%206%20-%20Frontend%20Avanzado/Reto%201%20-%20Implementaci%C3%B3n%20de%20seguridad%20en%20Symfony/README.md): aplicación Symfony con autenticación, autorización, roles, CSRF, voters y sanitización de contenido.
- [Reto 2 - Módulo de comentarios con Laminas](Nivel%206%20-%20Frontend%20Avanzado/Reto%202%20-%20Desarrollo%20de%20un%20m%C3%B3dulo%20reutilizable%20en%20Zend/README.md): módulo MVC para consultar, crear, editar y eliminar comentarios según los permisos del usuario.

- [Reto 4 - Plataforma de eventos](Nivel%206%20-%20Frontend%20Avanzado/Reto%204%20-%20Desarrollo%20de%20una%20aplicaci%C3%B3n%20web%20completa%20utilizando%20Angular%2C%20Spring%20Boot%20y%20MongoDB/README.md): aplicación full stack para gestionar eventos, con Angular, Spring Boot, MongoDB, autenticación JWT y pruebas de carga.
- [Reto 5 - Aplicación de notas Noto](Nivel%206%20-%20Frontend%20Avanzado/Reto%205%20-%20Implementaci%C3%B3n%20de%20una%20Progressive%20Web%20App%20%28PWA%29%20con%20Angular%20y%20Firebase/README.md): aplicación Angular de notas con calendario y tablero, sincronización con Firebase, funcionamiento offline y formato PWA.
